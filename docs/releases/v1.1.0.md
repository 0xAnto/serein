Serein's first public open-source Android release.

- Mix twelve offline soundscapes with individual layer and master volume controls.
- Save your own mixes or start with Sleep, Focus, and Unwind.
- Set a sleep timer with a fade and a countdown in the player, notification, and widgets.
- Keep listening in the background with notification and lock-screen controls.
- Use the breathing guide, light and night themes, and two home-screen widgets.
- No account, ads, analytics, or internet permission.

Requires **Android 12 or newer**.

Download **Serein.apk** below and open it on your Android device. Allow installation from your browser or file manager if Android asks. `SHA256SUMS` contains the APK's SHA-256 checksum. The source-code archives are for developers.

Development builds signed with a different key must be uninstalled first. Uninstalling removes saved mixes and settings. Later releases using the same release key can be installed as updates.
